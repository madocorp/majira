# MaJira

MaJira is a tile based Jira Cloud browser built with the current SPTK. Start it with `php majira.php` in a graphical session.

On first use, open **Settings** (F4), enter the Jira site URL, email and API token, then save and test the connection. The saved token is not shown on the screen when the app opens; leave its field blank to keep it. On **Filters** (F2), load and select a project and, if needed, a board and sprint. Project and sprint become JQL clauses. Board selection narrows the available sprint choices; it does not add a hidden constraint to ticket searches. The choice lists, ticket search, ticket details and filter options are cached in SPTK's private application data directory. Cached tickets are restored at startup. On **List** (F1), F5 refreshes the first page. When more results are available, the status bar shows the loaded count and M (or F6) loads the next page.

The **Filters** screen offers search and date inputs, status/type/priority/assignee lists, and saved JQL filters. Use **Load filter options** to fetch choices for the selected project. Name the staged choices and use **Save and apply named filter** to run them. The List sidebar starts with **Last JQL**, followed by saved filters. It highlights the active saved filter, or **Last JQL** after a direct edit. Return applies the highlighted item and activates the table when the search returns tickets; Esc closes the sidebar and restores the previous tile focus. Empty results leave the current tile focused. **Last JQL** restores the most recent direct edit after switching to a saved filter. Press F to open the sidebar, including while the ticket table is active. Alternatively, edit raw JQL on **List**; it runs when editing ends and activates the table if tickets are found. The **Ticket** screen (F3) shows details, allows summary and description edits and new comments, and provides **Open key** and **New ticket** actions. Jira requests appear in the status bar before they run.

The board layout XML remains an idea for a later board view and is not part of the active screen selector. The current pass does not yet include the old app's workflow transitions, attachment download, field chooser, comment editing, or complete filter menu. Jira requests run synchronously after their status message is drawn.

PHP extensions required by SPTK and the Jira client include FFI, SDL dependencies, XMLReader, mbstring, curl and pcntl. The application stores settings and Jira caches through `SPTK\Core\AppData`; keep that private directory out of version control.

Run `php Tests/JiraData.php` for the cache and paging check, and `php Tests/ListLayout.php` for the List sidebar layout check.
